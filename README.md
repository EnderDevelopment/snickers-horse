# Snickers – Max Horse Minecraft Plugin

Snickers is a Minecraft Paper plugin that gives players a horse with maximum breedable attributes, including health, speed, and jump height. Designed for Bedrock-compatible servers running Paper, this plugin adds a simple command to spawn a fully tamed, adult horse with optimized statistics for breeding and riding.

## Install

1. Download the `plugin.jar` file from the latest release.
2. Place the JAR file into your server's `plugins` folder.
3. Restart your server or run `plugman reload plugin` if you use PlugMan.

## Use

1. Ensure you have operator (`op`) status or the `maxhorse.use` permission.
2. Type `/maxhorse` in-game to spawn a horse with maximum health, speed, and jump height.
3. You can also use specific modes:
   - `/maxhorse health` – Horse with maximum health only.
   - `/maxhorse speed` – Horse with maximum speed only.
   - `/maxhorse jump` – Horse with maximum jump height only.
4. The command alias `/mh` works as a shortcut.
5. The spawned horse is instantly tamed, set as an adult, and assigned to you as its owner.
